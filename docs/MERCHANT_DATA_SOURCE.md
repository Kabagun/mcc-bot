# Источник MCC магазинов

Этот документ описывает источник именно для связи **«магазин → MCC»**.
Проценты манибэка, лимиты и условия банковских карт из `tannei.by` не
импортируются: бот рассчитывает выгоду только по своему каталогу карт.

Текущий снимок данных был собран **26 августа 2026 года** по минскому времени.
Доступность перечисленных ниже публичных страниц и запросов повторно проверена
**27 августа 2026 года**. Автоматической периодической синхронизации нет.

## Ссылки на источник

Основной источник — [карта манибэка tannei.by](https://tannei.by/moneyback/).

| Источник | Для чего использовался |
|---|---|
| `https://tannei.by/sitemap_index.xml` | Начальный список публичных магазинов и сетей |
| `https://tannei.by/sitemap.xml` | Резервный sitemap, если основной недоступен |
| `POST https://tannei.by/api/v2/moneyback/stores/search` | Магазины выбранной сети отдельно для офлайн- и онлайн-оплаты |
| `GET https://tannei.by/api/v2/moneyback/stores/item/{id}/` | Название, сеть, адрес и способ оплаты магазина |
| `GET https://tannei.by/api/v2/moneyback/stores/item/{id}/mcc/` | Наблюдавшиеся MCC и даты этих наблюдений |

Пример исходного ответа с MCC:
[`/stores/item/1960433/mcc/`](https://tannei.by/api/v2/moneyback/stores/item/1960433/mcc/).
Код импорта находится в
[`src/mcc_bot/import_stores.py`](../src/mcc_bot/import_stores.py), а правила
хранения и дедупликации — в
[`src/mcc_bot/stores.py`](../src/mcc_bot/stores.py).

На страницах магазинов tannei.by предупреждает, что MCC добавляют пользователи
сайта и реальный код операции может отличаться. Поэтому бот показывает
наблюдавшийся код, а точный MCC конкретной оплаты следует проверять в операции
банка. Пример такого предупреждения есть на
[странице магазина](https://tannei.by/moneyback/stores/1960433/).

## Как был собран снимок

1. Импортёр начинает с `sitemap_index.xml`, а при обычной ошибке источника
   пробует `sitemap.xml`.
2. Из sitemap берутся только HTTPS-ссылки домена `tannei.by` на публичные
   страницы магазинов `/moneyback/store/{id}/` или `/moneyback/stores/{id}/`
   и сетей `/moneyback/storenet/{id}/`.
3. Для каждой найденной сети дважды вызывается `stores/search`: отдельно с
   `"is_online": false` и `"is_online": true`. Так не смешиваются физические
   точки, сайты и приложения.
4. Для каждого найденного магазина запрашиваются точные сведения `item/{id}/`
   и его история `item/{id}/mcc/`.
5. Сохраняются исходный ID магазина и сети, канал оплаты, MCC, месяц
   наблюдения с исходной точностью, адрес и ссылка на источник.
6. Офлайн-точки объединяются только по точному ID сети от источника. Онлайн-
   магазины остаются отдельными записями. Сводный MCC сети не переносится
   автоматически на каждый филиал.

Вся собранная партия сначала проходит валидацию и лишь затем
публикуется одной SQLite-транзакцией. Внутри базы хранится одна сводка
tannei.by на публичный бренд: каналы, MCC, количество наблюдений,
диапазоны дат и контрольные хеши. Исходные ID точек и сетей остаются
в отдельных ссылках на источник для безопасной дедупликации повторного
импорта. Повторяющиеся строки evidence и автоматической истории для каждого
наблюдения не создаются. Независимо от числа точек и наблюдений, каждая
связь «бренд + канал + MCC» от tannei.by даёт ровно одно импортное подтверждение.

Импорт не опирается на неподтверждённые `limit` и `offset`: охват — это
объединение публично обнаруженных страниц и результатов точного поиска по
сетям, а не обещание полной копии внутренней базы tannei.by.

Запросы выполняются последовательно, не чаще одного раза в секунду, без cookie
и без обхода авторизации, CAPTCHA или блокировок. Ответы и прогресс сохраняются
в контрольных точках, поэтому прерванный импорт можно продолжить. При `401`,
`403`, CAPTCHA, HTML-странице блокировки или длительном ограничении частоты
импорт останавливается.

Для ручной проверки использовались обычные запросы без cookie:

```powershell
# Список публичных sitemap.
Invoke-RestMethod -Uri 'https://tannei.by/sitemap_index.xml'

# Физические магазины одной сети. Для онлайн-канала передаётся $true.
$body = @{ storenet_id = 1319671; is_online = $false } | ConvertTo-Json -Compress
Invoke-RestMethod `
    -Method Post `
    -Uri 'https://tannei.by/api/v2/moneyback/stores/search' `
    -ContentType 'application/json' `
    -Body $body

# Карточка магазина и наблюдавшиеся MCC.
Invoke-RestMethod -Uri 'https://tannei.by/api/v2/moneyback/stores/item/1960433/'
Invoke-RestMethod -Uri 'https://tannei.by/api/v2/moneyback/stores/item/1960433/mcc/'
```

Разница между количеством точек и магазинов ожидаема: филиалы одной сети могут

Старое наблюдение сохраняет свою дату и не помечается как проверенное в день
импорта.

В базе и отчёте охват явно обозначен как `publicly_discovered_only` — только
публично обнаруженные данные.

## Как повторить или проверить

Команды выполняются из корня репозитория в PowerShell 7:

```powershell
# Полный первый запуск или продолжение прерванного импорта.
.\.venv\Scripts\python.exe -m mcc_bot.import_stores --database var/stores.sqlite3 --resume

# Только текущие счётчики: без сети и без изменений базы.
.\.venv\Scripts\python.exe -m mcc_bot.import_stores --database var/stores.sqlite3 --status

# Ограниченный запуск; следующий --resume продолжит оставшиеся магазины.
.\.venv\Scripts\python.exe -m mcc_bot.import_stores --database var/stores.sqlite3 --resume --max-stores 10

# Проверка ответов источника без публикации данных в выбранную базу.
.\.venv\Scripts\python.exe -m mcc_bot.import_stores --dry-run --max-stores 3
```

Повторный запуск не создаёт дубли, не добавляет запись истории при полностью
неизменившемся источнике и не отменяет ручные исправления модераторов.
Файл `var/stores.sqlite3` содержит рабочие данные, исключён из Git и должен
сохраняться отдельно при обновлении приложения. После импорта поиск работает из
этой базы и не зависит от текущей доступности tannei.by.

## Ограничения

- Данные tannei.by основаны на пользовательских наблюдениях, а не на гарантии
  платёжной системы или банка.
- Один магазин может проводить разные операции с разными MCC. Канал, терминал,
  филиал и время наблюдения имеют значение.
- Публичные страницы и формат ответов tannei.by могут измениться после даты
  проверки этого документа.
- Снимок не считается полной копией внутренней базы сайта.
- Актуальные проценты манибэка и лимиты карт нужно менять в собственном каталоге
  проекта, а не брать из ответов tannei.by.
